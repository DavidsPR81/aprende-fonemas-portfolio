# Landing — Aprende Fonemas

Web estática en Netlify: [aprendefonemas.netlify.app](https://aprendefonemas.netlify.app)

## Local

Desde **esta carpeta** (`landing/`):

```bash
cd landing
npx serve .
```

http://localhost:3000/

Si ves el índice del monorepo, estás sirviendo la carpeta equivocada.

## Deploy

`netlify.toml` en la raíz apunta a `landing/`.
